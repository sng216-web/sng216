# AI-редакция Дзен

Технический каркас агентской редакции канала.

## Управление
Главный редактор — единственный управляющий агент.

## Агенты
1. Главный редактор
2. Исследователь
3. Контент-стратег / аналитик
4. Копирайтер
5. Редактор
6. SEO / Дзен-оптимизатор
7. Контролёр качества
8. Визуальный редактор / арт-директор
9. Генератор / обработчик изображений
10. Визуальный контролёр

## Контур публикации
Готовая статья → предпросмотр → Наталья → одобрение → сайт → ручной запуск RSS → Дзен.

**Важно:** автоматической отправки в RSS после одобрения нет.

## Слои
- Notion: состояние, задания, контекст, результаты.
- Агентский слой: промпты и маршрутизация.
- GitHub: версии конфигурации, схемы и preview-renderer.
- Сайт/RSS: публикационный контур после человеческого одобрения.
